# Forged-request protection on plain http

Version 1.8.3 stopped other websites from acting as someone who is signed in, but it left a gap on installs reached over plain `http`, such as `http://192.168.1.50:3000`. A page on another port of that same address could still send requests as a signed-in user. Those requests are now refused.

Nothing changes for installs on `https`, and no settings or database changes are needed.

## Upgrade

Pull `ghcr.io/mckenna654/freetoplay:latest`, or pin `:v1.8.4`. To go back, pin `:v1.8.3`.

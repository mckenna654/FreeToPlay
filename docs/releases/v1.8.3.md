# Fixes from a full code review

This update fixes ten problems found in a review of the whole project. No settings or database changes are needed.

## What's fixed

- **Crashes:** a failed Discord button click can no longer take the website down.
- **Forged requests:** another website can no longer change sessions or RSVPs for someone who is signed in, or sign them in as someone else.
- **Player limits:** a full session now refuses more confirmed players, on the web and in Discord. Maybe and can't make it still work.
- **Calendar days:** entries now appear on the correct day for each viewer, whatever timezone the server uses.
- **Cancelling:** Discord only hears about a cancellation once the session is really gone.
- **Covers:** session covers now only come from IGDB. Older sessions with covers from elsewhere show box art instead.
- **Startup:** the app now stops with a clear error when its port is taken, and the migration failure message no longer tells you to delete your database.
- **Local setup:** `prisma` commands now read `.env`.

## Upgrade

Pull `ghcr.io/mckenna654/freetoplay:latest`, or pin `:v1.8.3`. To go back, pin `:v1.8.2`. An optional `TZ` setting now sets calendar days for anyone with JavaScript turned off.

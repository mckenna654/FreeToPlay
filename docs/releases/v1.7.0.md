# Squad up. Game on.

FreeToPlay now looks and feels like a co-op gaming lobby. This release replaces the old dashboard styling with midnight backgrounds, violet and lime accents, bold game-menu typography, a new controller logo, and original sci-fi artwork.

![FreeToPlay gaming lobby](https://raw.githubusercontent.com/mckenna654/FreeToPlay/v1.7.0/docs/screenshots/lobby-banner.png)

## A new look across the app

- Redesigned lobby, session details, roster, and scheduling form.
- New FreeToPlay wordmark, Discord thumbnail, and browser icon.
- Larger game tiles, clear player availability, and controller artwork when a session has no cover image.
- Updated desktop and mobile screenshots in the [README](https://github.com/mckenna654/FreeToPlay/blob/v1.7.0/README.md#screenshots).

## Easier to get the squad together

- Switch between a monthly calendar and an agenda; phones default to the agenda.
- Search sessions by game, title, or host.
- Filter for open spots or your own sessions.
- Download individual sessions as calendar events (.ics) and copy invite links.
- Create a session straight from a calendar date.
- Preview a session while filling out the form.
- Navigate IGDB game suggestions with the keyboard, or enter any game name manually.

## Fixes and reliability

- Selected start times now preserve the browser's timezone when saved on servers in other timezones.
- Form validation keeps entered details when something needs correcting.
- Session creation and the host's confirmed RSVP are saved together.
- IGDB suggestions render safely as text and handle stale requests.
- Corrected development-mode asset and template paths.
- Nine integration tests now run during the Docker build. Desktop and mobile browser checks covered session creation, RSVP updates, search, filters, keyboard selection, and layouts from 320–1440 px.

## Upgrade

Use `ghcr.io/mckenna654/freetoplay:v1.7.0` or `ghcr.io/mckenna654/freetoplay:latest` and recreate your existing container, keeping its data volume and environment variables.

There are no database schema changes in this release. Existing Discord and IGDB credentials continue to work. Calendar month boundaries use the server's timezone; configure `TZ` (for example, `Australia/Sydney`) to match your group.

Screenshots use sample players and sessions.
